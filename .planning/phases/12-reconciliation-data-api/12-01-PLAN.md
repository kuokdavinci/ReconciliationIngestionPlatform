    Add the following query methods to `ReconciliationResultRepository`:

    ```python
    async def find_by_partner_and_date(
        self, partner: str, date: str
    ) -> list[ReconciliationResult]:
        """Find all results for a partner on a specific date."""
        return await self.find_many({"partner": partner, "date": date})

    async def find_by_partner_date_and_status(
        self, partner: str, date: str, status: ReconciliationStatus
    ) -> list[ReconciliationResult]:
        """Find results for a partner+date filtered by reconciliation status."""
        return await self.find_many({
            "partner": partner,
            "date": date,
            "reconciliationStatus": status.value,
        })

    async def count_by_status(
        self, partner: str, date: str
    ) -> dict[str, int]:
        """Aggregate reconciliation results by status using MongoDB aggregation.

        Returns dict like {"MATCHED": 1450, "AMOUNT_MISMATCH": 30, ...}
        Uses $group on reconciliationStatus field.
        """
        pipeline = [
            {"$match": {"partner": partner, "date": date}},
            {"$group": {"_id": "$reconciliationStatus", "count": {"$sum": 1}}},
        ]
        cursor = self.collection.aggregate(pipeline)
        result = {}
        async for doc in cursor:
            result[str(doc["_id"])] = doc["count"]
        return result

    async def get_total_amounts(
        self, partner: str, date: str
    ) -> dict[str, Optional[Decimal]]:
        """Get sum of partner_amount and internal_amount for a partner+date.

        Returns dict like {"total_partner_amount": Decimal("..."), "total_internal_amount": Decimal("...")}
        Uses $sum on amount fields. Both are optional — returns None if no data.
        """
        pipeline = [
            {"$match": {"partner": partner, "date": date}},
            {
                "$group": {
                    "_id": None,
                    "total_partner_amount": {"$sum": "$partnerAmount"},
                    "total_internal_amount": {"$sum": "$internalAmount"},
                }
            },
        ]
        cursor = self.collection.aggregate(pipeline)
        async for doc in cursor:
            from bson.decimal128 import Decimal128
            pa = doc.get("total_partner_amount")
            ia = doc.get("total_internal_amount")
            return {
                "total_partner_amount": pa.to_decimal() if isinstance(pa, Decimal128) else (Decimal(str(pa)) if pa is not None else None),
                "total_internal_amount": ia.to_decimal() if isinstance(ia, Decimal128) else (Decimal(str(ia)) if ia is not None else None),
            }
        return {"total_partner_amount": None, "total_internal_amount": None}
    ```

    **Step 2: Create `src/api/reconciliation.py`** — FastAPI router for reconciliation endpoints

    Create an `APIRouter(prefix="/api/v1/reconciliation")` with:

    **GET /results** — List reconciliation results
    - Query params: `partner` (str, required), `date` (str, required, YYYY-MM-DD), `status` (str, optional), `limit` (int, default=100, max=1000), `offset` (int, default=0)
    - Access DB via `request.app.state.db["reconciliation_result"]` plus `ReconciliationResultRepository`
    - Date validation: check YYYY-MM-DD format, raise HTTP 400 if invalid
    - Partner validation: raise HTTP 400 if empty
    - When `status` provided: use `find_by_partner_date_and_status`
    - When no `status`: use `find_by_partner_and_date`
    - Apply limit/offset in-memory on the returned list (simple approach, adequate for MVP since reconciliation results per partner/date are typically &lt;5000)
    - Response JSON:
      ```json
      {
        "results": [ReconciliationResult as dict],
        "total": 150,
        "limit": 100,
        "offset": 0
      }
      ```
    - Error handling: catch exceptions → 500 with `{"detail": "..."}`

    **GET /results/{id}** — Get single reconciliation result by partner_txn_id
    - Path param: `id` (str, the partner_txn_id which is the MongoDB _id)
    - Use `ReconciliationResultRepository.find_one({"_id": id})`
    - Return 404 if not found
    - Response: single ReconciliationResult dict

    **GET /stats** — Aggregated reconciliation statistics
    - Query params: `partner` (str, required), `date` (str, required, YYYY-MM-DD)
    - Uses `count_by_status` and `get_total_amounts` from the repository
    - Response JSON:
      ```json
      {
        "partner": "MOMO",
        "date": "2024-07-07",
        "total": 1500,
        "by_status": {"MATCHED": 1450, "AMOUNT_MISMATCH": 30, ...},
        "total_partner_amount": "500000000.00",
        "total_internal_amount": "500000000.00"
      }
      ```
    - Amounts returned as strings (Decimal serialization) for JSON compatibility

    **Validation helpers (as module-level functions):**
    ```python
    def _validate_date(date_str: Optional[str]) -> str: ...
    def _validate_partner(partner: Optional[str]) -> str: ...
    ```
    Reuse the pattern from `src/api/insights.py` — consistent validation across all API modules.

    - All endpoints are GET-only (read-only)
    - No authentication/authz for MVP (same as existing insights API)
