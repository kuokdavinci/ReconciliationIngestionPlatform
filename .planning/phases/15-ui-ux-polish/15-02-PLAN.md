<objective>
**Dashboard Layout Restructure & Dead UI Removal**

Reorder the Dashboard/Overview page so partner/date filters appear below the total metrics section (not above it). Remove the non-functional "Regenerate AI Analysis" button since the underlying API does not support on-demand regeneration.

**Purpose:** The current layout places partner/date filters at the very top of the page above the metrics cards, which creates visual clutter before the user sees key numbers. The "Regenerate AI Analysis" button triggers a toast message but has no working backend — removing it cleans up the interface.

**Output:** Restructured Overview template in app.js with filters moved below metrics, dead button removed.
</objective>
