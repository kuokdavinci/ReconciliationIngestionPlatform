# Plan 18-02: Frontend — Use decisionActions from backend

## Goal

Update the frontend to consume the backend's separate `decisionActions` field for the Decision step instead of filtering secondary actions by hardcoded keys. No visible behavior change — the 3-step modal already exists, this is a tighter coupling to the backend contract.

## Tasks

1. Update `renderCopilotBrief` to read `copilot.decisionActions` array for Decision-step buttons. Define `decisionKeys` reference from `decisionActions` field.
2. Remove the hardcoded `decisionKeys` array and inline `secondaryActions.filter(...)` — decision actions are no longer mixed into `secondaryActions`.
3. Decision step still shows recommendation block + primary CTA + decision buttons only when `decisionActions` array is non-empty.
