# Plan 19-03: Bidirectional Handoff Integration

## Goal

Complete the bidirectional handoff loop between Review Center and Mapping Studio. When Studio hands off, the review item appears in Review Center. When Review Center sends to Studio, the mapping config pre-loads.

## Tasks

### Task 1: Backend — endpoint to create review packet from mapping

Create `POST /api/v1/review-packets/from-mapping/{mapping_id}` in `src/api/review_packets.py`. Takes a completed mapping config ID and creates a review packet from it, returning the new packet ID. This is the Studio → Review Center direction.

### Task 2: Frontend — handoff POST → navigate to Review Center

Wire the confirm handoff button to call the new backend endpoint. After success: toast "Mapping submitted for review.", navigate to `#review-queue`.

### Task 3: Frontend — clear studio state on fresh opens

Ensure `state.studio` fields (`reviewItemId`, `draftMappingId`, `handoffConfirmed`, etc.) are cleared when opening Studio from Data Intake (not from Review Center). Store the entry point so the correct behavior applies.
