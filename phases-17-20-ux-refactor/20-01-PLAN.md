# Plan 20-01: Reconciliation — Filters + AI Insights Panel

## Goal

Add amount range (min/max) and date range (from/to) filters to the reconciliation view. Add an AI Insights panel above the results table with 4 segmented tabs: Summary, Anomalies, Patterns, Recommendations.

## Tasks

### Task 1: Add filter controls to reconciliation view

In `renderReconciliation()`, add amount range + date range filter inputs below the status tabs. Wire the existing `state.reconStatus`, `state.explorerFilters` pattern. Add filter buttons: Apply and Clear.

### Task 2: Add AI Insights panel

Render an AI Insights section above the results table with 4 tabs:
- **Summary** — matched/unmatched counts, total amounts, percentages
- **Anomalies** — AI-detected anomalous transactions
- **Patterns** — patterns in unmatched data
- **Recommendations** — AI-suggested actions

Fetch from `/api/v1/reconciliation/insights?type={tab}&partner={}&date={}`. Show loading state per tab. Cache responses in state.

### Task 3: Add CSS for insight panel

Add `.insights-panel`, `.insights-tabs`, `.insight-tab`, `.insight-content`, `.insight-card` styles.

### Task 4: Create backend insights endpoint (if not exists)

If `/api/v1/reconciliation/insights` doesn't exist, create it in the reconciliation API router.
